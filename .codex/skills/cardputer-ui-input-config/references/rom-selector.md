# ROM Selector Reference

ROM selector branch features to preserve:

- Paged navigation
- Search opened by the established shortcut
- Cursor restore after entering and leaving folders
- Extension filtering by enabled core
- Clear error display before returning to the list
- Support for SD directory indexes where present

When changing supported extensions, update both:

- The visible extension list
- ROM type detection

Do not show files that cannot be launched in the current build.
